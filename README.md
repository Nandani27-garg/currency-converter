# 💱 Currency Converter

A responsive currency converter built with **HTML, CSS, and JavaScript**. The app fetches exchange-rate data from the ExchangeRate API and converts amounts between supported currencies.

## ✨ Features

- 🌍 Multiple currency support
- 🔄 Dynamic exchange-rate API integration
- 💰 Instant currency conversion
- 🎨 Clean responsive dark UI
- ⚡ Dynamically populated currency dropdowns
- 📱 Mobile-friendly design
- 🛡️ Input validation and API error handling

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript (ES6+)
- ExchangeRate API

## 🚀 Run Locally

```bash
git clone https://github.com/Nandani27-garg/currency-converter.git
```

Open the project folder and launch `index.html` in a browser. No backend or build step is required.

## 📂 Project Structure

```
currency-converter/
├── index.html
├── style.css
├── script.js
└── README.md
```

## 🌐 API

The app uses:

`https://open.er-api.com/v6/latest/{currency}`

Rates are fetched dynamically for the selected source currency.
